# LALA RESTAURANT (SULTHANS BRIYANI) - Official Website

A single-file, fully responsive, interactive website for **LALA RESTAURANT (SULTHANS BRIYANI)** located in Sivaganga, Tamil Nadu.

## 🚀 How to Run / Preview

### Option 1: Double Click
Simply double-click [`index.html`](file:///c:/Users/yoghan/OneDrive%20-%20ELCOT/Desktop/lala/index.html) in your file explorer to open it directly in any web browser (Chrome, Edge, Firefox, Safari).

### Option 2: Python Local Server
Run Python's built-in HTTP server in this directory:
```bash
python -m http.server 8000
```
Then navigate to `http://localhost:8000` in your web browser.
